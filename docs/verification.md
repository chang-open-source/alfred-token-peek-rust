# 验证记录

以下区分自动验证与开发阶段的真实服务验证，不能将模拟结果视为账号连通性证明。

## 自动验证

- Rust 测试覆盖 JSON 解析、未知与零值区分、筛选、缓存过期、失败保留、进程超时、并发刷新及 Claude 安装检测。
- Python 测试覆盖发版版本校验、上游资产与摘要、Changelog 生成和最低 macOS 要求。
- 格式检查与 Clippy；Alfred plist 和动作脚本格式检查。
- 双架构 Rust 构建、官方 CodexBar 资产 SHA256 校验、许可证与资源打包。
- 实际安装包校验包括权限、版本、架构、最低系统要求、带空格路径及模拟 CLI 查询。
- CI 运行宿主架构的 CLI，对另一架构做静态检查；不等同于在两种实体机器上的端到端验证。

## 开发阶段实机验证（2026-11-17）

- 在 Alfred 5.8.1 中导入并验证查询、筛选和非阻塞手动刷新。
- Codex 经内置 CLI 和 Rust 调用链成功解析额度窗口。
- Claude 真实查询曾在 20 秒后超时，尚未确认账号连通性；不能归因为未登录或服务故障。
- 桌面版检测仅确认安装，不验证或改变其登录态复用。
- 未持久化原始 CLI 账号响应或凭据。
